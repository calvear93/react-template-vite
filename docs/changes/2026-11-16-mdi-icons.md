# The icons of the kit as Material Design Icons

## Goal

Draw the 66 icons of the kit from Material Design Icons (the outlined shape where there is one)
instead of lucide, under the names the kit already has.

Dropped: it was built and looked at in the catalog, and it read worse. The shapes of Material
Design are heavier and squarer than the rounded line of lucide, next to the glass and the thin
type of the shell. The icons stay lucide shapes, and nothing of this change was kept.

## Not included / assumptions

- If the set is ever changed, the candidates with a rounded line are Phosphor and Tabler; a
  generated registry (a file naming the source of each icon, and a script that writes the
  registry from the package) worked well here and is worth doing again.
